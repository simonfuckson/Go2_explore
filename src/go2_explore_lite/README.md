# GO2 定制 explore_lite

继承小车定制 explore_lite 的前沿、覆盖缺口选点、已知空间检查、失败目标冷却与候选轮转。GO2 版本统一读取机器狗轮廓、外参和地面配置，删除小车几何默认值。历史来源和许可证见 `UPSTREAM_AND_CHANGES.md`、源文件头和 `package.xml`；旧变更记录不作为 GO2 操作指南。

运行方式见工作空间根目录 README。目标生成器由探索监督器启动/关闭，独立 ROS Master 中只有一个 move_base。预测未知地面收益只用于排序，不修改已观测空闲图。测试包括 GO2 轮廓、旋转/路径可达性、覆盖缺口与视野收益。
